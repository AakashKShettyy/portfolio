# Hero character

The hero uses the template's original avatar (`character.enc`, decrypted in the
browser by `src/stage/avatar/decrypt.ts`), dressed in a black suit, white shirt, red
tie, mustache and beard by `src/stage/avatar/styleAvatar.ts` and `beard.ts`.
